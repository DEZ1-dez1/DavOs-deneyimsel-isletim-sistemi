# DavOs-deneyimsel-isletim-sistemi
DavOS, x86 16-bit gerçek kip (real mode) üzerinde çalışan, kendi bellek yöneticisine (bitmap tabanlı sayfalama), hiyerarşik RAM dosya sistemine, x87 FPU destekli gelişmiş hesap makinesine ve özel bir karakter/sembol paletine sahip bağımsız bir custom mini işletim sistemi projesidir.
